# 방지플랜 PRO v0.1 — 실무 검토용 시제품

제조업 설비목록과 국소배기 후드·덕트 기초자료를 입력·계산·정리하는 브라우저 기반 웹프로그램입니다.

## 📱 바로 사용하기

배포 성공 후 사이트 주소: https://cute-00.github.io/bangjiplan-pro/

**GitHub Pages 설정**: 저장소 Settings → Pages → Source **GitHub Actions** 로 지정해야 합니다.

상세 배포 실행 결과: https://github.com/cute-00/bangjiplan-pro/actions

## 현재 제공 기능
- 설비별 관리번호·공정·기계명·동력·수량 목록
- 후드별 CMM 입력 및 총풍량 합계
- 원형/사각형 덕트 단면적·유속 계산
- 기계설비 목록 및 국소배기 계산 목록 CSV 다운로드
- JSON 백업·복원 및 인쇄용 보고서
- 브라우저 내 자동저장 (localStorage)

## 주의
- v0.1은 **실무 자료정리용 시제품**이며 법정 제출용 완성 프로그램이나 공인 계산기가 아닙니다.
- 풍량·유속 결과와 단위, 제어풍속·반송속도·압력손실·설비 적합성 및 관련 법령은 담당자가 별도로 검증해야 합니다.
- 저장 내용은 **현재 브라우저/기기 내부(localStorage)** 에 보관됩니다. 같은 계정으로 다른 기기에서 열어도 자동 동기화되지 않으며, 브라우저 데이터 삭제 시 사라질 수 있으므로 **JSON 백업**을 권장합니다.
- 웹사이트 주소와 **소스코드는 공개**됩니다. 사용자 입력은 기본적으로 서버에 저장하거나 전송하지 않지만, 민감한 도면·고객정보는 시제품에 넣지 마세요.
- 실제 고객에게 판매하기 전 인증, 저장·복구, 개인정보 보호, 결제, 유료사용권, 계산 검증 및 전용 보안 운영환경이 필요합니다.
